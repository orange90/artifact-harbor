# Artifact Harbor

使用本 Skill 随附的 `scripts/archive.py` 执行操作。需要 Python 3.10+，无第三方依赖；当前支持 macOS / Linux 的已挂载 SMB、NFS、AFP 网络共享。用 Skill 所在目录的绝对路径调用脚本，不依赖用户当前目录。默认状态目录为 `~/.local/share/codex-nas-archive`，可通过 `CODEX_NAS_ARCHIVE_HOME` 或 `--state` 指定。

## 文件找回规则（本 Skill 的持久规则）

**找不到的文件，先去 NAS 里找。**

用户在会话中要求继续编辑某个文件时，若本地原文件缺失：
1. 执行 `python3 <skill>/scripts/archive.py find '<原路径、文件名或会话关键词>'` 查询本地归档索引；结合原路径与会话 ID 确认正确产出。不能因为本地缺失而直接重新生成替代内容。
2. 唯一匹配已归档版本时，执行 `restore <文件ID>`。恢复是完成用户编辑请求的必要步骤，无需重复询问已授权的找回操作。
3. 检查恢复命令结果为成功，再读本地原文件并继续修改。恢复会下载到原路径并校验 SHA-256；原路径存在不同文件时禁止覆盖。
4. 多个匹配无法消歧时请用户选择；NAS 离线时说明需要重新挂载；索引无结果时说明尚未找到，不宣称文件已丢失或恢复成功。

此规则只属于 Skill。**不要写入用户长期偏好或用户级 AGENTS.md，不向长期记忆累积文件名。** 逐文件映射、版本位置与迁移状态由本地 SQLite 索引和 NAS manifests 保存。Skill 被加载时遵循该流程；不能承诺未加载 Skill 的所有会话都会被自动拦截。需要确保触发时，可显式使用 `$codex-nas-archive`。

## 首次使用：一步步引导

启动 `python3 <skill>/scripts/archive.py serve`，读取打印的完整 Dashboard URL，在 Codex 浏览器中打开（令牌位于 URL fragment）。进程必须保持运行；终止后重新启动会生成新 URL。

Dashboard 的引导顺序为：
1. **归档时间**：7 天、1 个自然月、3 个自然月，或自定义。使用用户选择，不替用户固定为 30 天。
2. **NAS 连接**：填写可选 `smb://主机/共享名` 与实际已挂载目录。Mac 可在 Finder 按 ⌘K 挂载；凭据由系统管理。QuickConnect/DSM 管理网址不是文件共享目录。用户点击连接验证后，程序创建目标标识并做 4 KB 写读删除测试。
3. **范围与缓冲**：配置扫描根目录、本地副本保留天数（默认 7 天），以及独立的 NAS 清理建议期限（默认 6 个自然月，可改为天或关闭）。扫描只读 Codex 会话数据库，处理已关联会话的 outputs 媒体文件，不移动会话数据库、正文或源码。多个会话共用目录、置顶会话和新文件会跳过。
4. **预览**：保存并扫描，展示真实候选文件，用户再选择迁移。可以跳过 NAS 连接先看扫描结果；扫描不上传、不删除文件。

如果用户只要求计划、扫描或查看，不执行批量迁移/释放，不创建定时自动化。用户在界面选择迁移授权复制所选文件；“释放本地空间”单独展示数量和确认，再由程序重新校验后清理。已有明确对应授权时，CLI 可直接完成，不重复要求确认。

## NAS 长期未使用清理建议

Dashboard 提供“NAS 清理建议”与“建议清理 NAS”筛选。建议本身只供人工复核，不修改会话、不把待复核大小计入已释放空间。用户可进一步预览删除清单并明确确认删除所列 NAS 对象。迁移期限和 NAS 清理建议期限是两个独立设置。

- 使用记录来自本工具成功取回/恢复，以及用户明确表示最近使用过后的 `mark-used` 登记。失败恢复、浏览列表、搜索、扫描和完整性校验不能计为使用。
- 按归档时间、观察开始时间、最近使用记录三者的最晚时间计算；超过设置期限且未标记“始终保留”，才列入建议。成功恢复或登记使用后重新计时。
- 不声称能监测 Finder、NAS 网页或其他应用的访问。不依赖 NAS 的 atime，因为挂载策略及校验读取可能让它失真。告知用户这只是本工具记录下的清理建议，真正删除前还应核对外部使用及是否为唯一副本。
- 已存在的旧归档从首次升级启用访问记录时开始观察，不能将历史没有记录解释为从未访问。
- 仅在用户明确说最近用过时登记 `mark-used`，不能因查看建议而自动登记，也不将文件名和访问记录写入用户长期记忆。

## 确认后删除 NAS 归档

Dashboard 的“删除 NAS 归档…”先生成清单，展示 NAS 路径、大小，以及本地原路径是否有 SHA-256 一致的完整副本。标明无已验证本地副本的文件可能失去唯一归档；用户必须输入“删除 NAS 归档”、勾选理解提示，再点击永久删除按钮。

CLI 对应 `delete-preview <文件ID> ...`，返回 10 分钟有效的一次性确认 token。只有用户已经明确确认这份具体清单后，才可执行 `delete-confirm --token <token> --phrase '删除 NAS 归档'`。要求开发此功能、查看建议或生成预览，不代表已确认删除具体文件。若通过浏览器执行最终删除，还应遵守当前计算机工具的逐次确认规则。

- 预览及确认均校验 NAS 对象。确认时再次检查归档版本、最近使用、保留状态；预览中存在的本地完整副本若变化或消失，必须重新预览确认。
- 删除只作用于清单中当前索引指向的 NAS 文件对象，不删除本地文件、会话或整个目录，不清除未列出的历史版本。不会绕过“始终保留”。
- 文件删除后，本地索引保留“NAS 已删除”状态与时间，远端 manifest 尽力写入删除标识。找回时遇到此状态，不能承诺可从 NAS 恢复；先检查原路径是否仍有本地文件，再说明实际可用副本。
- 该操作不经过本工具回收站。NAS 自身的快照、回收站和存储回收策略可能影响实际空间释放，不能保证恢复或保证立即回收等量空间。
- 中断后只核对删除结果；仍存在的对象不会自动重试删除，必须重新预览确认。

## 操作入口

```
python3 <skill>/scripts/archive.py scan
python3 <skill>/scripts/archive.py status
python3 <skill>/scripts/archive.py find '关键词'
python3 <skill>/scripts/archive.py archive <文件ID> ...
python3 <skill>/scripts/archive.py release <文件ID> ...
python3 <skill>/scripts/archive.py restore <文件ID> ...
python3 <skill>/scripts/archive.py exclude <文件ID> ...
python3 <skill>/scripts/archive.py include <文件ID> ...
python3 <skill>/scripts/archive.py mark-used <文件ID> ...
python3 <skill>/scripts/archive.py delete-preview <文件ID> ...
# 以下命令仅在用户确认具体删除清单后执行：
python3 <skill>/scripts/archive.py delete-confirm --token <token> --phrase '删除 NAS 归档'
```

操作前检查命令返回的逐文件结果。迁移失败保留本地文件；校验通过不代表本地已清理。空间统计按文件分配块估算，APFS 克隆和快照会影响实际可用空间，不能把上传字节直接算成节省空间。

Dashboard 仅监听 `127.0.0.1`，API 使用每次启动生成的令牌，不将其暴露到公网。NAS 断开、目标身份不匹配、源文件更新、保留期未结束时，清理应停止。不要绕过这些检查或用手工 `rm` 替代。

维护、恢复索引或适配新 Codex 数据结构时，阅读 [references/architecture.md](references/architecture.md)。
